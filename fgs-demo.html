FOREGROUND_SERVICE_DATA_SYNC — how DropNest uses it

Package com.dropnest.app. Declared task: Network processing → Other.

What the service does

DropNest transfers files directly between the user's own devices over the local Wi-Fi network — there is no cloud. The foreground service keeps the encrypted receive server running so that a transfer the user started from another device completes even when this phone's screen is off or the app is in the background; otherwise Android would kill the connection mid-transfer.

  • Started only when the user opens the app; never on boot or by a push.
  • Shows a persistent notification ("Ready to receive on …") with a Stop action while running.
  • Stops when the user taps Stop, quits the app, or when Android's data-sync time limit is reached (onTimeout).
  • No data leaves the local network; nothing is uploaded to any server.

What the video shows

The phone opens another device's box, fetches files, and the transfer finishes while DropNest's notification is visible; the received files then open from the Transfers screen.
